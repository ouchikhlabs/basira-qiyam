# منظومة القيم في منهاج التربية الإسلامية – حصة تكوينية رقمية

حصة تكوينية رقمية مصغرة (30 دقيقة) يستعملها الأستاذ المكوّن لتدريب الطلبة الأساتذة على تحليل منظومة القيم في منهاج التربية الإسلامية.

- **السند:** حق الله: الوفاء بالأمانة والمسؤولية · الأولى باكالوريا · مدخل القسط
- **المرجع:** منهاج التربية الإسلامية، مديرية المناهج، يونيو 2016 (الصفحتان 8 و22)

## المراحل
1. الوضعية المهنية (00–05)
2. الخريطة التفاعلية الرسمية (05–15)
3. الربط بالدرس وورشة التصحيح (15–25)
4. التقويم الرقمي والتغذية الراجعة (25–30)

واجهة الأستاذ المكوّن: زر ⚙ أعلى الصفحة.

> الرسومات التفاعلية تخطيطات تنفيذية، وليست صوراً رسمية من المنهاج. المحتوى العلمي والنصوص الشرعية تراجع قبل التسليم.
